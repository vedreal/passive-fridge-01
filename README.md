One funny passive-aggressive note a smart fridge leaves for its owner: a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

> "Your leftovers from Tuesday have started a new life in here. I have named it Kevin. Kevin pays rent now."

## Run it

```sh
python3 main.py
```

The program writes the note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
